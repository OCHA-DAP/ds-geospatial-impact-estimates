Sign in with an emailed link

Enter the address your organisation registered. If it is on the provider list in Listmonk, a one-time link arrives from the team's un.org address. Addresses not on the list get nothing, and the page says the same thing either way so the list cannot be probed.

The link signs in the browser it is opened in and the session then lasts 30 days on that device. Only three test addresses are on the list for this spike.

Also tested: sign-in through Microsoft or GitHub accounts

The Static Web App's built-in sign-in. It works, including for Microsoft accounts outside the UN tenant, but it requires an account with one of those providers and an invitation per person, so the emailed link above is the preferred path. Kept here as the fallback.
