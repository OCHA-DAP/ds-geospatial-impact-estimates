Behind the map

How this map is made

This viewer doesn't rely on any single assessment — it puts every source on the same footing so they can be compared directly. Each damage dataset is projected onto one shared base of Overture building footprints, so every source is expressed in the same unit: buildings. A footprint is counted as damaged for a source when that source's data lands on it — Microsoft footprints are matched directly, Copernicus EMS and HotOSM damage points are snapped to the nearest building within 20 m, and the radar sources (IMPACT SAR, OSU) are sampled building-by-building. That shared base is the common denominator that makes “what does each source say here?” an answerable question.

Just as important, a source is only credited where it actually looked. Every source carries its own area of interest — a Copernicus activation footprint, a radar swath, a model's coverage mask. Inside it a building is analysed; outside it the source simply has no data, which is very different from “looked and found nothing.” So a source is never penalised for ground it never covered, and every rate is measured against what was actually assessed.

Hover any admin unit or hexagon and, for every source, you'll see the same figures:

Total buildingsEvery building in the unit — the Overture base count.
AnalysedBuildings inside the source's area of interest — what it could actually see.
CoverageAnalysed ÷ total — how much of the unit the source assessed.
Damage fractionDamaged ÷ analysed — the share of assessed buildings found damaged.

These per-building results are rolled up to OCHA COD admin units (levels 0–3) and an H3 hexagon grid, with damage grades aligned across every source to the Copernicus EMS scale — Possibly · Damaged · Destroyed. Select any mix of sources and each admin unit or hexagon is coloured by the strongest signal among them — so one source's coverage gap is filled by another's, and you can always open the hover to see exactly which source drove the number.
